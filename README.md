# 지구의 운동 퀴즈

초등 과학 6학년 1학기 「4. 지구의 운동」 10문제 실시간 퀴즈 (5조).

- 학생: 사이트 주소(또는 QR)로 들어와 이름을 넣고, 휴대폰에서 색깔 버튼으로 답을 고릅니다.
- 진행자: 주소 끝에 `?host`를 붙여 열고 비밀번호를 넣습니다. 큰 화면에 띄워 문제·정답·해설·순위를 보여 줍니다.

## 파일
- `index.html` — 앱 전체 (문제 10개 포함)
- `config.js` — Firebase 주소, 퀴즈 칸 이름, 진행자 비밀번호
- `img/` — 문제 그림(q2, q6)과 해설 그림(expl1~10)
